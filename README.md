# 🎨 AI Image Generator

>  Generate high-quality AI images from natural language prompts through an intuitive web interface.

---

# 📖 Overview

**AI Image Generator** is an AI-powered web application that transforms text prompts into visually rich images using modern generative AI models.

Built with **Gradio**, **PyTorch**, **Transformers**, and **Diffusers**, the application provides an interactive interface for generating creative visuals from simple natural language descriptions.

Whether you're an artist, designer, developer, or AI enthusiast, this tool makes AI-powered image generation fast, simple, and accessible.

#  Installation

Clone the repository

```bash
git clone https://github.com/RohithaKavala/ai-image-generator.git
```

Navigate to the project directory

```bash
cd ai-image-generator
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python app.py
```
